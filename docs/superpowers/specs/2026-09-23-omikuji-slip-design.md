# 籤紙改成御神籤（設計）

日期：2026-09-23　分支：`feat/3d-cylinder-rebuild`　狀態：使用者已同意設計

## 為什麼

神社主題（[`2026-09-23-shrine-theme-design.md`](2026-09-23-shrine-theme-design.md)）做完之後，使用者說
「很好！那籤也幫我重新設計」。現在的籤紙是中式古籍版式（四角回紋、朱絲欄、金石大字），放在
神社場景裡不搭。使用者在兩個方向裡選了「日本御神籤紙」（另一個是可愛雜貨風的橫式籤卡）。

## 設計

### 1. 籤紙本體（`StickFace` large）

細長的白色和紙，寬 `min(340px, 100%)`，朱紅雙線邊框（外 2px、內 1px，相隔 4px），紙上保留淡淡的纖維紋，
四角回紋拿掉。由上而下：

1. **表頭**：一條朱紅橫帶，反白字「御 神 签」（英文籤「O M I K U J I」）；帶子下方一行小字：
   中文「第十七签」（國字數字，`hanNumber`），英文「NO. 17 OF 36」。
2. **等級大紅印**：直徑 92px 的朱紅圓印、內有一圈奶油色細環，反白寫等級（`LEVEL_LABEL`）。
   三個字（上上签）22px、兩個字 26px；英文分兩行、12px 粗體。
   落印動畫沿用四種籤運各自的 keyframes（重印、琥珀墨暈、水紋、沉香微雲），改成套在整顆印上；
   各籤運的光暈（`level-stamp-aura`）照舊在印的後面，是四種籤運唯一保留顏色的地方之一。
3. **籤名**：左右各一條 18px 的朱紅細線（取代「」與 ✦）。
4. **籤詩**：中文維持直排三欄（兩句詩 + 一句籤意），欄線改淡朱紅虛線、欄高 150px；英文維持橫排。
5. **底部**：「吉色 · 金黄」小膠囊（色點用籤運色 `--tone`，另一個保留顏色的地方）置中，
   右下角一朵朱紅櫻花小印。

框、表頭、印一律朱紅（`--seal: #c0321f`），抽到哪一種籤都像同一間神社印的。

### 2. 所求之事 → 繪馬

結果頁上方的問題卡改成跟題目頁一樣的繪馬（紅繩、小字、水引），寬 `min(360px, 100%)`。
繪馬上的小字跟**這一局的語言**走（`copyFor(reading.language).emaCaption`），不跟界面 ——
AGENTS.md 第 9 條：紙上說問題的語言。`EmaChrome` 加一個可選的 `caption` 參數。
繪馬的 CSS 從 `.shell:has(.cyl3d-stage) .ask-zone` 泛化成也吃 `.ema-card`，木頭色票移到 `:root`。

### 3. 解籤按鈕 → 朱紅漆木札

`.sheet-actions .lead-action`：朱紅漆底、奶油色字、4px 圓角、細亮邊與陰影，hover 浮起 1px。
結果頁其他動作（分享、追問、再求一签）維持一行字。

### 4. 版面

`.sheet-stack` 不再是一整卷紙（拿掉背景與陰影）：繪馬、籤紙、按鈕、解籤續頁各自是場景裡的物件，
籤紙與續頁各自帶紙色與陰影。容器寬 400px，繪馬 360、籤紙 340、續頁撐滿 400。

### 5. 共用

`hanNumber` 從 `src/app/cylinder/materials.ts` 搬到 `src/shared/numerals.ts`（兩邊共用、加測試）。

### 不動的

籤的內容、語言規則、四個小標題的語言、解籤續頁的內部版式、求籤記錄的迷你版（`slip-mini`）。
印表機模式走紙時吐出的也是這張新籤紙（同一個元件）。

## 驗收

- `numerals` 單元測試：1..36 全對（十、十一、二十→廿、廿三、卅六）。
- `npm test`、`npm run check` 通過。
- 瀏覽器：中文、英文籤各看一次；上上签（三個字）與上签（兩個字）的印都放得下；
  減少動畫時印直接出現；手機 375 寬沒有橫向捲軸。
