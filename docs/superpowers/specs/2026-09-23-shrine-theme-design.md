# 神社日光主題：繪馬、木札、櫻花（設計）

日期：2026-09-23　分支：`feat/3d-cylinder-rebuild`　狀態：使用者已同意設計

## 為什麼

籤筒定案之後，使用者說「背景、對話框、suggestion 可以更有日式那種感覺，來點櫻花飄落、神社之類；
對話框可以小一點，現在太大」，並給了一張參考拼貼（日光下的神社：朱紅鳥居、掛著的木牌、
繪馬、布幔、燈籠、木製路標、手水舍，四處是櫻花）。

從參考圖抽出來的語彙：

- **材質**：淺木（木牌、繪馬、路標）、米白和紙與布幔
- **色**：奶油、朱紅、一點櫻花粉，暖色日光
- **符號**：紅色水引蝴蝶結 + 一條橫線、紅色櫻花／梅花小印
- **字**：寬字距圓體大寫；副標「OMIKUJI · JAPAN · GOOD LUCK」這種點隔小字
- **場景**：兩側朱紅鳥居柱、角落櫻花枝、花瓣飄落；紅繩掛著的木牌與繪馬

使用者選了「繪馬 + 木札」方向（另一個選項是保留無框、只換符號），並選了「一律白天版」。

## 設計

### 1. 一律白天

拿掉 `styles.css` 裡兩段 `@media (prefers-color-scheme: dark)` 的覆寫，`color-scheme: light`。
`--ink*` 與 `--on-ground*` 兩套仍然分開用（AGENTS.md 第 8 條），只是不再反轉。

### 2. 背景：神社日光（`ShrineBackdrop`）

一個 `position: fixed`、`pointer-events: none`、`aria-hidden` 的圖層，在所有內容後面，
只在 game 路由掛。

- **光**：奶油 → 蜂蜜色的暖漸層，左上一片柔和的日光（radial-gradient）。
- **鳥居柱**：畫面最左、最右各一根朱紅柱（含上方一小截笠木的影子），模糊（`blur(3px)`）、
  低不透明度，像景深外的背景。寬度 < 900px 時藏起來。
- **櫻花枝**：左上、右上角各一枝，inline SVG（枝條 + 五瓣花），不需要外部圖檔。
- **飄落的花瓣**：一張 canvas 2D，電腦約 18 片、手機約 10 片；每片會下落、左右擺、翻面
  （水平縮放 = cos 翻轉相位）。
  - 動力學是純函式，放在 `src/shared/sakura.ts`（不碰 DOM，vitest 測得到）：
    建立（確定性亂數）、推進一格（跟幀率無關）、掉出下緣就從上緣重生。
  - 減少動畫（頁面開關或系統設定）：只畫幾片靜止花瓣，不跑 rAF。
  - 分頁看不見時停掉 rAF。
  - 解籤頁（籤紙出來之後）花瓣減到一半、再淡一點，不干擾閱讀。

### 3. 題目寫在繪馬上

只在 3D 籤筒台上（`.shell:has(.cyl3d-stage)`）套用；印表機等其他器具不變。

- 寬 `min(420px, 100%)`，比現在的 720px 框小。
- 形狀：五角形繪馬 —— `clip-path: polygon(0 22px, 22px 0, calc(100% - 22px) 0, 100% 22px, 100% 100%, 0 100%)`，
  用 px 定角，所以寫到兩行、牌子變高時角不會被拉歪。兩層疊出木邊：外層深木色、內層淺木色
  加細木紋（`repeating-linear-gradient`）。陰影用父層的 `filter: drop-shadow`（`clip-path` 會吃掉 `box-shadow`）。
- 上方一條紅繩掛著：從牌頂正中往上分成倒 V，中間一個小結（CSS 偽元素）。
- 牌上由上而下：
  1. 小字「絵馬 · 心願」（英文介面「EMA · MAKE A WISH」）—— 紅色、寬字距圓體；
  2. 題目（現有的 `.ask-input` / `.ask-ghost`）—— 深棕色明體；
  3. 紅色水引蝴蝶結 + 橫線 + 一朵櫻花印（inline SVG）。
- 牌上的字用 `--ink*` 那套（木牌是「紙」那一側的東西），新增 `--wood*` 色票。
- 兩行不跳：`.ask-slot` 仍預留兩行的高度，牌子往上長（`justify-content: flex-end`）。
- 按下之後（`.asked`）：題目留在同一塊繪馬上，只是不能再改。

### 4. 例句是三塊小木札

- 每塊：淺木色、圓角 4px、1px 深木色邊、左邊一朵紅色櫻花小印，字是深棕色明體 13px。
- 一排三塊、置中，間距 12px；上窄（繪馬）下寬（木札），構圖是穩的。
- hover / focus：往上浮 2px、轉 1°，像被碰了一下。
- 寫字之後照舊淡出、但保留位置（不讓籤筒跳）；按鈕同時 disabled。
- 英文介面或寬度 < 860px：直排、每塊寬度一致。

### 5. 專案規則

- AGENTS.md 第 7 條改寫：題目寫在繪馬上、例句是木札；**不加一般的輸入框**，新 UI 做成機器上、
  紙上或神社場景裡的物件。
- AGENTS.md 第 8 條：拿掉「深色模式會反轉」那句，改成「目前只有白天版」。
- i18n：新增 `emaCaption` 一個鍵，中英兩張表都要有（缺一個 build 會失敗）。

### 6. 不動的

籤筒與出籤動畫、籤紙與解籤頁的排版、印表機等其他器具。

## 驗收

- `sakura.ts` 單元測試：花瓣永遠在畫面水平範圍內或正在重生；推進跟幀率無關；
  掉出下緣會從上緣回來；同一個種子兩次結果相同；減少動畫時不動；壞掉的輸入不產生 NaN。
- 瀏覽器：1440×900、1000×640、375×812 三種大小不捲動（`scrollHeight == innerHeight`）、
  沒有橫向捲軸；繪馬寬 ≤ 420px；中文木札一排、英文直排；花瓣在動；減少動畫時不動。
- `npm test`、`npm run check` 通過。
