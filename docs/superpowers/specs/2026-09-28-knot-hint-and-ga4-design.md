# 讓人知道結可以點，以及 GA4 的留存與時間

日期：2026-09-28　狀態：使用者已同意設計

## 為什麼

繩上的結（見 2026-09-28-collection-and-knots-design.md）現在只有「點了才知道」。使用者：
「只要想辦法讓 users 知道那裡可以看就好，其他先不用；然後確保 GA4 能夠追蹤指標，尤其是留存跟在
app 裡的時間。」

## A. 結的提示

選定：**打結後自己解開一下，再加微光**（否決：只做微光太含蓄、只做自動解開只有一次機會、加一行小字
要跟規則 7「求籤畫面只有一行步驟文字」商量）。

- 兩個只存在這台瀏覽器的旗子：`wenyiqian.knotSeen`（親手點開過一個結；自動解開不算）、
  `wenyiqian.knotPeeked`（結已為了提示自己解開過一次）。規則是純函式，
  `src/shared/knot-hint.ts`（`glowKnots`、`peekOnTie`、`readKnotHint`），有測試。
- **微光**：所有結周圍一圈慢慢呼吸的金色光暈，直到 `knotSeen`。用 SMIL `<animate>` 而不是 CSS 動畫，
  才不會跟結自己的晃動（`knot-sway`）和冒出來（`knot-tie`）搶同一個 `animation` 屬性。
  減少動態時是不動的一圈。漸層畫在那條一定看得見的繩上，藏起來的舊結（手機）才拿得到它。
- **自動解開**：還沒 `knotSeen`、也還沒 `knotPeeked` 時，下一個新綁上去的結冒出來後自己解開，垂下小籤紙
  約 5 秒再收回（沿用隔天回訪那一段，同一套機制）。只一次；錯過的人之後靠微光。
  已經有結、但從沒點過的老使用者，在他們下一次打結時也會遇到這一次。
- 隔天回訪的自動解開也算「已經解開過」（`knotPeeked`），但不算 `knotSeen`。
- 清掉本機資料（`clearLocalData`）連同兩個旗子一起清。沒有新文字，所以不需要新文案。
- 不動：伺服器、D1、`#settings`、結的位置與外觀、隔天回訪的行為。

## B. GA4

線上標籤已經在送（`G-86RWKZYYJB`，Consent Mode v2，PR #48）。**留存與「平均參與時間」是 GA4 的內建指標，
不需要程式**：`_ga` 給的 client id 讓「留存」與「探索 → 世代」報告能算第 1、7、28 天；
`user_engagement` 的 `engagement_time_msec` 只算畫面在前景的時間，是「平均參與時間」的來源。
使用者選擇先用內建參與時間，不另外做「只算解讀出現後」的計時（解讀等待會被算進去，這是已知的缺點，
看數字不夠用再加）。

程式只加一個事件：`knot_opened`，親手點開一個結時送，**不帶任何參數**（沒有籤號、問題、解讀）。
它回答「提示有沒有用」：有結的人裡，多少人點開過。自動解開不送。

### GA 後台要自己設的（程式碰不到）

1. **事件資料保留期改成 14 個月。**預設只有 2 個月，探索報告的第 28 天留存會被截斷。
   （管理 → 資料收集與修改 → 資料保留。標準報告不受影響。）
2. 把 `reading_completed` 標成關鍵事件。
3. 想按語言拆數字，就把事件參數 `language` 註冊成自訂維度。
4. 歐盟、英國、瑞士的訪客按「同意」前是無 cookie 的（`analytics_storage` 預設 denied），
   留存與參與時間會偏低。這是設計如此，看數字時要記得。

### 本機開發不要報進正式的 GA

`wrangler.jsonc` 帶的是正式 id。本機 `.dev.vars` 要有 `GA_MEASUREMENT_ID=G-TESTLOCAL0`
（`.dev.vars.example` 已經寫了；`.dev.vars` 被 git 忽略）。

## 測試

- `tests/knot-hint.test.ts`：微光到 `seen` 為止、只自動解開一次、`seen` 之後兩者都停、壞值當沒有。
- 本機實測（桌機與手機寬度）：老使用者（有結、沒點過）看到微光 → 新打一個結，它自己解開、5 秒後收起、
  `knotPeeked=1` 且微光還在 → 再打一個不再解開 → 點一個結：`knot_opened` 送出（沒有參數）、
  `knotSeen=1`、微光消失 → 重新整理不再出現。同意後 `g/collect` 有送出（同意前 `gcs=G100`，同意後 `G111`）。
- 沒能在預覽驗證：`user_engagement`／`_et`。它在分頁隱藏或關閉時才送，預覽窗格一直是隱藏的。
  上線後用 GA4 DebugView 看。
