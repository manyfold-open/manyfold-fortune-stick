# 分享的便宜實驗：上上籤、下籤推一把

## 為什麼

1048 支籤只分享 3 次（0.3%），分享進來的訪問是 0。獎勵這條路已經有了（抽一支就能再玩一次塔羅），
所以這次試的是籤本身的分享動機：抽到上上籤想炫耀、抽到下籤想自嘲。量很小（一天約 200 支），
只有拉高好幾倍的改動量得出來，所以挑動機，不挑按鈕顏色。

## 做什麼

**只有上上籤與下籤（36 支裡 11 支，約三成）**，結果頁背面：
- 分享那排上面一行小字（界面語言）：上上籤「上上签！传给朋友沾点好运」，下籤「下签……传给朋友，让他帮你挡一挡」。
- 分享是朱紅木札 —— 即使是 Tarot 訪客（上一個 PR 讓他們的分享讓位給領取塔羅，極端籤例外）。

其餘七成的籤照舊，就是對照組：同一段時間兩邊的分享率並排比，不用等前後期。

**所有籤的分享文字與連結預覽**改成挑戰口吻（紙的語言，`PAPER[lang].challenge`）：
「我抽到上上签，你呢？」；朋友打開連結，繪馬寫「朋友抽到上上签，换你试试手气」（`friendDrew`，取代 `sharedEma`）。

**量測**（`daily_stats`，不改 schema）：
- `share:opened` —— 打開分享面板；`share:extreme-opened` / `share:extreme-done` —— 極端籤的打開與真的分享出去
- `readStats` 從 `readings.stick_no` 讀出每天的極端籤抽出數（`extremeDraws`）
- `#settings` 新區塊「分享實驗」：打開分享 → 真的分享出去的比率；極端籤與其餘籤的分享率並排。
  從 `SHARE_EXPERIMENT_SINCE`（上線後第一個完整日）起算。

## 不變

問題、解讀照舊不進分享圖和連結。Tarot 獎勵、領取木札不動。無新框：一行字和木札顏色。

## 測試

- `isExtreme`、11 支極端籤；`share:*` 新計數收得到；回溯的 `extremeDraws`
- 五種語言的 `challenge` / `friendDrew` 無連字號、韓文與英文不夾漢字
- 本地：抽到上上籤／下籤看到小字與朱紅分享；中籤沒有；Tarot 訪客抽到極端籤時兩塊朱紅木札；
  打開分享送出 `share:opened`；朋友連結 `?s=1&l=zh` 的繪馬字；`#settings` 的分享實驗區塊
