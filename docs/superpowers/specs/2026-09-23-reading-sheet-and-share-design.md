# 解籤續頁與分享圖跟上神社主題（設計）

日期：2026-09-23　分支：`feat/3d-cylinder-rebuild`　狀態：使用者已同意（「可以都改」）

## 為什麼

籤紙改成御神籤之後（[`2026-09-23-omikuji-slip-design.md`](2026-09-23-omikuji-slip-design.md)），使用者截了兩張圖：
分享圖還是舊的金色菱格底＋「问一签 · FORTUNE PRINTER」牌記＋中式格子；解籤續頁還是金色等寬小標、
虛線撕痕、一行字的動作。兩樣都要跟上。

## A. 解籤續頁（`.sheet`）：御神籤的第二頁

- 紙：同一種白和紙，一條朱紅內框細線；拿掉頂上的虛線撕痕。
- 頂上一條小朱紅帶「解 签」（英文籤「READING」）—— 新 i18n 鍵 `sheetBand`，用
  `copyFor(reading.language)`（跟四個小標題一樣跟這一局的語言走）。
- 四個小標題：朱紅圓體，前面一朵櫻花小印；「一句话签意」大一號、下方一條朱紅細線；
  「值得留意／可以做的一件小事」兩欄，中間一條淡朱紅豎線。
- agent 沒連上的提示：淡朱紅底便條；「重试解签」是小木札。
- 動作列：「收起分享」「继续追问」是小木札，「再求一签」是朱紅漆木札（主要動作）。
- 分享／追問：標題用同一種朱紅小標；勾選框朱紅；「生成并分享」朱紅漆木札；追問的問答標籤朱紅、
  歷史摺疊票與快速提問改淡木色。
- 解籤中：轉圈與掃描光改朱紅。

## B. 分享圖（1080×1350）

- 背景：神社日光 —— 奶油暖漸層、左上日光、兩側朱紅鳥居柱（含黑色笠木）、兩角櫻花枝、
  散落花瓣（`src/shared/sakura.ts`，固定在 t = 7.3s 畫，每張圖一樣）。
- 勾了「在图片中显示我的问题」：問題寫在上方一塊掛著的繪馬上（紅繩、小字、水引）；沒勾就不畫繪馬，
  籤紙往上移。
- 中間：跟頁面同一張御神籤 —— 朱紅雙線框、表頭帶「御神签」、國字籤號、大紅印（外圈籤運色光暈）、
  籤名左右朱紅細線、直排籤詩＋一句話籤意（有解讀用解讀的，沒有用籤本身的）、吉色膠囊、櫻花印；
  英文橫排。
- 底部：「问一签 · 签为参考，路要自己走」與網址。
- 四種籤運不再換底色，只留在印的光暈與吉色色點。
- 拆檔：`src/app/shareScene.ts` 畫背景、繪馬、印、櫻花小印；`share.ts` 只管排版與分享。

## 不動的

分享的隱私規則（預設不放問題、不放完整解讀與追問）、分享／下載／複製文字的降級流程、
解籤的內容與語言規則。

## 驗收

- `npm test`、`npm run check` 通過。
- 瀏覽器：直接呼叫 `renderShareImage` 產生中文（含問題／不含問題）與英文三張圖，逐張看；
  用 StickFace 同樣的方法把一份假的解讀掛上 `.sheet` 看版面（不真的呼叫 agent）；手機 375 寬沒有橫向捲軸。
